# Suites Angelica Website

Clean Next.js website for Suites Angelica in Bucerias.

## Included pages

- Home: `/`
- Properties: `/properties`
- Contact: `/contact`
- Individual apartment pages: `/properties/suite-101` through `/properties/suite-402`

## Not included

This project intentionally does not include About or Services pages.

## Notes

The project uses neutral placeholder SVG images created for Suites Angelica. Replace files in `public/images/` with real photos when available.

## Run locally

```bash
npm install
npm run dev
```
